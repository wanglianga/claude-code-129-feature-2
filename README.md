# 社区舞蹈队 · 排练报名与演出走位协作台

React 18 + TypeScript + Zustand + Vite 实现的单页应用。围绕**同一场演出记录**，让队长、队员、服装负责人、文化站、音响师、志愿者六类角色协同完成：报名 → 排练签到 → 走位编排 → 服装 → 节目审查 → 演出当天 → 归档 的完整流程。

## 本地启动

```bash
npm install        # 安装依赖
npm run dev        # 开发模式，默认 http://localhost:5173
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm run preview    # 预览生产构建，默认 http://localhost:4173
npm test           # 运行 store 层冒烟测试（47 项断言）
```

### Docker 一键启动（无需本机 Node）

```bash
docker compose up -d --build   # 构建并启动，浏览器访问 http://localhost:8080
docker compose down            # 停止
# 或仅用 Dockerfile：
# docker build -t community-dance-stage . && docker run -p 8080:80 community-dance-stage
```

> 镜像采用多阶段构建：Node 20 构建静态产物，Nginx 托管，最终镜像不含源码与构建依赖。

## 功能与异常场景对照

- **报名**：队长发布广场舞/民族舞/合唱伴舞/节庆演出（可标记文艺汇演海选）；记录队员年龄、联系方式、服装尺码、可排练时间、是否参加正式演出、身体注意事项。
- **排练签到**：平板大按钮出勤/请假/缺席；上传曲目版本（自动通知音响师）；动作分段与重点练习成员标记；老年队员健康提醒条。
- **走位编排**：队形网格（前排高亮）；最近排练请假/缺席的队员站位标红闪烁，队长可快速发现前排缺席影响；队员点击放置/撤下；**场地缩小**一键压缩列数，被裁队员进入「待安置」并生成调整记录与通知；队形变化说明。
- **服装**：押金收取、本人/家属代领登记、归还退押金；**尺码返换闭环**——领取后登记试穿照片、原尺码、期望尺码与领取人，服装负责人按尺码盘点并确认可换库存；确认可换则换货（库存自动 -1、原押金延续）；演出前无货可换时队长可**调整站位将就**（自动写入走位调整记录）或**启用备用服装**（押金、清洗责任、归还时间重新记录，归还时统一结算押金）；服装负责人通过「长期紧缺尺码看板」查看哪些尺码长期紧缺以便补货采购；押金状态在换货、备用、归还各环节全程同步。
- **文化站**：节目主题/人数/时长/音响需求/场地审批；节目审查（「要求调整节目内容」会退回排练阶段）；报名→排练→走位→服装→审核→现场签到连续性链条；多支队伍排练室排期。
- **演出当天**：候场顺序（可提前/延后）、现场签到、现场临时通知、志愿者引导要点、音响需求确认。
- **演出档案**：签到汇总、服装归还、走位调整记录、现场照片、下次活动通知。
- **其他**：排练室多队共用（同时段同室冲突自动拦截）、老年队员健康提醒专页（按注意事项生成提醒建议）。

## 验证方式与结论

实际执行过的验证（2026-09-30）：

1. `npm run build`：TypeScript 严格模式类型检查 + Vite 生产构建通过（58 个模块，无类型错误）。
2. `npm test`：store 层冒烟测试 **47/47 通过**，覆盖：报名生成服装押金记录、请假/缺席识别、走位唯一站位、场地缩小裁列（待安置+日志+通知）、曲目版本更新通知音响师、审查退回/通过流转、押金/家属代领/归还、排练室冲突拦截、现场签到、候场顺序调整、流程连续性判定；以及新增的**尺码返换闭环**——
   - 试穿照片 / 原尺码 / 期望尺码登记，进入待返换列表；
   - 服装负责人确认有货 → 换货更新尺码、可换库存自动 -1、报名尺码同步、原押金延续；
   - 确认无货 → 进入待队长决策 → 调整站位（写走位日志+紧缺记录+通知）；
   - 启用备用服装（押金/清洗责任/归还时间重录）→ 收备用押金 → 归还记录实际归还时间并结算押金；
   - 长期紧缺尺码按「无货/备用/调站位」累计次数统计并标记。
3. `npm run dev` 启动后 `curl http://localhost:5173/` 返回 200；`npm run preview` 生产预览 `curl` 返回 200。

页面手动验证路径（右上角切换角色）：

- 切到「服装负责人」→ 服装管理：选择《丰收锣鼓》，可见赵淑珍 L 偏小的试穿照片、原尺码与期望 XL、库存盘点表（XL 为 0）；对其他队员可「盘点确认」、对偏小记录「确认有货/无货」。
- 切到「队长」→ 服装管理：展开缺货记录，可「调整站位将就」（去「走位编排」页能看到新增的调整记录），或「启用备用服装」填写备用尺码/押金/清洗责任/归还时间，再「收备用押金」「归还备用服（退押金）」。
- 服装负责人在页面底部「尺码长期紧缺看板」查看 XL 等长期紧缺尺码；「总览」页对队长/服装负责人显示缺货待决策与长期紧缺红色/金色预警；「演出档案」查看归档节目的原码→现码、返换处置与备用服装押金/清洗/归还记录。

> Docker 镜像构建需本机装有 Docker；当前开发沙箱无 Docker 守护进程，已提供多阶段 `Dockerfile` 与 `docker-compose.yml`，可在有 Docker 的环境用 `docker compose up -d --build` 一键启动（访问 8080）。
